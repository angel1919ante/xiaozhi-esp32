# EDITH WHA103

Профиль для платы, которую штатная прошивка идентифицирует как `WHA103`.
Её компоненты и распиновка совпадают с семейством Tenclass Xmini C3: ESP32-C3,
ES8311, усилитель NS4150B и OLED SSD1306 128x64.

Профиль намеренно имеет свой тип `edith-wha103`, чтобы OTA-обновления EDITH не
пересекались со штатным профилем Xmini C3.

Исходный Xmini C3 записывает eFuse `VDD_SPI_AS_GPIO`. Эта операция необратима,
поэтому в профиле EDITH она отсутствует: штатная прошивка уже успешно загружается
с внешней 16 MB flash, а повторно менять eFuse не требуется.

Перед прошивкой нужно собрать этот профиль и проверить OLED, звук, микрофон и
кнопку BOOT на подключённой плате.
